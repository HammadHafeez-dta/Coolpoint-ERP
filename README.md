# FMS Web Client

This directory contains the React, TypeScript, and Vite web client for CoolPoint ERP. Repository-wide setup, backend commands, and database deployment notes are in the [root README](../README.md).

## Run locally

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

Configure the API URL through the local environment files used by Vite. Do not commit secrets or environment-specific credentials.
